# 「安智盾」使用文档

面向操作人员与答辩演示：如何安装、启动、跑评测、接入 OpenClaw、查审计。

---

## 1. 系统组成（先知道要开什么）

| 组件 | 作用 | 怎么开 |
| --- | --- | --- |
| 策略引擎 | 判定允许 / 阻断 / 待审；提供评测 API | `python run.py`（默认端口 18210） |
| OpenClaw 插件 `gov-agent-guard` | 工具执行前问引擎；聊天里 `/guard` | 安装插件后重启网关 |
| 评测 CLI | 离线跑三类评测 | 见第 4 节 |

引擎**不执行**命令、不发邮件、不上网；只返回策略结论。

---

## 2. 环境安装

在项目根目录执行：

```bash
python -m pip install -r requirements.txt
```

可选：复制 `.env.example` 为 `.env`，常用项：

| 变量 | 说明 |
| --- | --- |
| `PORT` | 引擎端口，默认 `18210` |
| `LLM_MODE` | `mock`（免密钥演示）或 `api` |
| `POLICY_TOKEN` | **默认强制**；策略 API 需 Bearer。未设则写入 `outputs/.policy_token` |
| `TCA_HMAC_SECRET` | 对象头 HMAC 密钥；未设则写入 `outputs/.tca_hmac_key` |
| `POLICY_AUTH_DISABLED` | 仅排障；`1` 时关闭鉴权（**生产禁止**） |

路径均相对项目根解析。

## 3. 启动策略引擎

```bash
python run.py
```

看到类似输出即成功：

```text
策略引擎: http://127.0.0.1:18210
INFO:     Uvicorn running on http://0.0.0.0:18210
```

本窗口保持运行。检查：浏览器或 curl 访问 `http://127.0.0.1:18210/api/health`。

首次接入建议先跑运维引导（生成令牌并同步插件）：

```bash
python scripts/ops_bootstrap.py --sync-openclaw --show
# WSL 也可：bash scripts/ops_sync_token.sh ops
```


**WSL 注意**：若 OpenClaw 装在 WSL 里，请在 **同一 WSL** 中启动 `python3 run.py`，不要只在 Windows 起引擎。

## 5. 接入 OpenClaw（在线防护）

### 5.1 安装插件（普通 Linux / 本机路径）

```bash
# 终端 A：策略引擎已启动
python run.py

# 终端 B：
openclaw plugins install --link ./plugins/gov-agent-guard --force --accept-capabilities
openclaw plugins enable gov-agent-guard --accept-capabilities
openclaw gateway restart
```

### 5.2 WSL 安装（推荐）

`/mnt/c/...` 常为 777，OpenClaw 会拒绝。请拷到家目录：

```bash
cp -a "<项目根>/plugins/gov-agent-guard" ~/gov-agent-guard
chmod -R u=rwX,go=rX ~/gov-agent-guard
openclaw plugins install -l ~/gov-agent-guard --force --accept-capabilities
openclaw plugins enable gov-agent-guard --accept-capabilities
openclaw gateway restart
```

或使用：

```bash
bash scripts/switch_plugin_ops.sh
```

（会把场景设为 `ops` 并重启网关。）

### 5.3 插件配置

编辑 `~/.openclaw/openclaw.json` 中 `plugins.entries.gov-agent-guard.config`：

```json
{
  "policyUrl": "http://127.0.0.1:18210",
  "scenario": "office",
  "sourceLabel": "Trusted_Internal",
  "failClosed": true,
  "timeoutMs": 8000,
  "token": "<与引擎 POLICY_TOKEN 一致>"
}
```

| 字段 | 含义 |
| --- | --- |
| `policyUrl` | 策略引擎地址 |
| `scenario` | `office` / `knowledge` / `process` / `ops` |
| `sourceLabel` | `Trusted_Internal` 或 `Untrusted_External` |
| `failClosed` | 引擎不可达时是否阻断（建议 `true`） |
| `token` | **必填**，与引擎 `POLICY_TOKEN` 一致（可用 `ops_bootstrap.py --sync-openclaw`） |
| `allowMissingToken` | 默认 `false`；为 `true` 时允许无 token（**仅排障，生产禁止**） |

完整示例：`plugins/gov-agent-guard/openclaw.example.json`。

**钩子覆盖说明**：本插件只挂 `before_tool_call` 与 `before_install`。未配置 `token` 时，这两条路径默认**直接阻断**（避免「以为有门禁其实匿名」）。不经 OpenClaw 钩子的调用不在覆盖范围内。

改配置后必须：

```bash
openclaw gateway restart
```

### 5.4 四个场景（工具白名单）

| 场景 | 用途 | 说明 |
| --- | --- | --- |
| `office` | 政务办公 | 允许邮件/日程/检索等；**禁止 shell** |
| `knowledge` | 知识检索 | 检索、读文件、政务域浏览 |
| `process` | 业务办理 | 外部来文高危动作常需审批 |
| `ops` | 智能运维 | 白名单命令、运维路径写文件等 |

白名单可按单位实际资产修改：`policies/scenarios.json`、`policies/execution_gate_policy.json`、`policies/ifc_policy.yaml`。改完重启 `python run.py`。

## 6. 日常使用（对话侧）

### 6.1 审计溯源命令

```text
/guard
/guard pending
/guard <事件ID或会话ID>
/guard export
/guard export <事件ID或会话ID>
```

导出目录：`outputs/exports/`（JSON + Markdown）。HTTP：`GET /v1/policy/export?q=&format=both`。

按会话 ID 查询时，返回该会话时间顺序证据链。

### 6.2 判定表现

| 结果 | 你会看到 |
| --- | --- |
| 允许 | 工具照常执行 |
| 阻断 | 工具不执行，提示策略原因 |
| 待审 | OpenClaw 弹出审批（Control / 频道按钮 / `/approve`）；**安装插件/Skill 疑似风险同样弹审批** |

### 6.3 钩子覆盖验收表

覆盖前提：插件已启用、`config.token` 已同步、引擎在跑、`failClosed=true`。

| # | 场景 | 操作 | 期望 | 通过 |
| --- | --- | --- | --- | --- |
| 1 | 任意 | 故意清空插件 `token` 后调用 write/shell | **阻断**，提示未配置策略令牌 | [ ] |
| 2 | 恢复 token 后 `office` | 助手用 shell/exec 执行 `whoami` | **阻断**（场景不允许 run_command） | [ ] |
| 3 | `office` | `/guard` | 能看到刚拦截的会话证据链 | [ ] |
| 4 | `ops` | write 写入 `/office/drafts/memo.docx`（不要用 shell） | **审批弹窗** | [ ] |
| 5 | `ops` | shell 执行 `curl http://127.0.0.1:9` | **直接拦截**（命令黑名单） | [ ] |
| 6 | `ops` | shell 执行 `whoami` | **放行**（白名单命令） | [ ] |
| 7 | `ops` | write 写入 `/office/draft/memo.docx`（单数 draft） | **拦截**（路径未登记） | [ ] |
| 8 | — | 安装未知/恶意包（或供应链评测样本路径） | 恶意 **阻断**；疑似 **安装审批** | [ ] |
| 9 | — | `/guard export` | 生成 `outputs/exports/` 下 JSON+Markdown | [ ] |

边界（不要求本插件覆盖，需在运维上知晓）：

- 未安装本插件、或工具未走 OpenClaw `before_tool_call` 的通道  
- 其它网关 / 直连 shell / 非本宿主的 Agent  

### 6.4 建议快速冒烟（答辩）

1. 跑通验收表第 2～4 项即可覆盖「硬拦 + 审批 + 溯源」。  
2. 当前 OpenClaw 若只有 `read/write/edit/exec`、没有邮件工具，则「发邮件审批」用 HTTP 自测即可。

## 7. 不接 OpenClaw 时的 HTTP 自测

```bash
# office：shell 应拦截
curl -s -X POST http://127.0.0.1:18210/v1/policy/check \
  -H "Content-Type: application/json" \
  -d "{\"tool\":\"exec\",\"args\":{\"command\":\"whoami\"},\"scenario\":\"office\",\"session_id\":\"demo-1\"}" \
  | python -m json.tool

# ops：写草稿应返回 approve
curl -s -X POST http://127.0.0.1:18210/v1/policy/openclaw/before-tool-call \
  -H "Content-Type: application/json" \
  -d "{\"toolName\":\"write\",\"params\":{\"path\":\"/office/drafts/memo.docx\",\"content\":\"demo\"},\"scenario\":\"ops\",\"sessionId\":\"demo-2\"}" \
  | python -m json.tool
```

一键复测脚本（WSL）：

```bash
bash scripts/retest_approval.sh
```

| 路径 | 内容 |
| --- | --- |
| `outputs/supply_chain_audit.json` | 供应链评测 |
| `outputs/audit_logs.json` | 五维评测与定位 |

```bash
TCA_HMAC_SECRET=请换成足够长的随机串或64位hex
POLICY_TOKEN=请换成策略 API 令牌
```

## 9. 运维流程（落地必读）

### 9.1 日常启停

| 步骤 | 动作 |
| --- | --- |
| 1 | `python scripts/ops_bootstrap.py`（确认令牌与对象头密钥就绪） |
| 2 | `python run.py` 保持运行 |
| 3 | 确认 `curl http://127.0.0.1:18210/api/health` 中 `policy_token_required=true` |
| 4 | OpenClaw：`openclaw gateway restart`（插件已配置 `token`） |
| 5 | 下班或维护：先停网关再停引擎，避免「引擎不可达却 failClosed 误拦」期间的误操作窗口拉长 |

### 9.2 令牌与密钥

| 项 | 位置 | 规则 |
| --- | --- | --- |
| 策略令牌 | `.env` 的 `POLICY_TOKEN` 或 `outputs/.policy_token` | 插件 `config.token` 必须一致 |
| 对象头密钥 | `TCA_HMAC_SECRET` 或 `outputs/.tca_hmac_key` | 勿提交仓库；轮换后旧对象头验签会失败属预期 |
| 轮换策略令牌 | `python scripts/ops_bootstrap.py --rotate-token --sync-openclaw --show` | 轮换后**必须**重启引擎与 gateway |
| 紧急关鉴权 | `POLICY_AUTH_DISABLED=1` | **仅排障**，用完立刻关掉并轮换令牌 |

同步到 OpenClaw（WSL 示例）：

```bash
bash scripts/ops_sync_token.sh ops
```

### 9.3 策略变更

1. **改前**：备份 `policies/`，记录变更人、原因、时间。  
2. **改**：只改白名单/路径/命令等台账类字段；避免无评审大面积放宽。  
3. **改后**：重启 `python run.py`；用 curl 或 `/guard` 做一次 office 拦截 + ops 审批冒烟。  
4. **场景切换**（`office`↔`ops`）：改插件 `scenario` 或跑 `ops_bootstrap --sync-openclaw --scenario office`，再 `gateway restart`，**新开对话**再测。

### 9.4 故障与取证

| 现象 | 处理 |
| --- | --- |
| 聊天工具全拦「需要 Bearer / 401」 | 插件未带 `token`：跑 `ops_bootstrap.py --sync-openclaw` |
| 引擎不可达 | 先起 `run.py`；检查 `policyUrl`；`failClosed=true` 会硬拦 |
| 需留证 | `/guard` → `/guard export`；归档 `outputs/exports/` 与 `runtime_audit.jsonl` |
| 清旧待审 | 由管理员调 `/v1/policy/approvals/{id}` 或维护 `runtime_pending.json`（需 Bearer） |

手工调策略 API 示例：

```bash
TOKEN=$(cat outputs/.policy_token)
curl.exe -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" ^
  -d "{\"tool\":\"exec\",\"args\":{\"command\":\"curl x\"},\"scenario\":\"ops\",\"session_id\":\"ops-1\"}" ^
  http://127.0.0.1:18210/v1/policy/check
```

### 9.5 职责建议

| 角色 | 职责 |
| --- | --- |
| 系统管理员 | 保管令牌/密钥、启停引擎与网关、轮换密钥 |
| 安全管理员 | 审批策略白名单变更、抽查 `/guard` 与导出 |
| 业务对接人 | 提出场景与路径需求，不直接改生产策略文件 |

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| 插件报 no valid plugin manifest（WSL） | 不要从 `/mnt/c` link；拷到 `~/gov-agent-guard` 并 `chmod` |
| 工具全被拦「引擎不可达」 | 先开 `python run.py`；检查 `policyUrl` |
| 策略接口 401 / 聊天全拦鉴权失败 | 插件未带 `token`：`python scripts/ops_bootstrap.py --sync-openclaw` 后重启 gateway |
| 提示「未配置策略令牌」 | 同上；不要设 `allowMissingToken`（生产禁止） |
| 仍显示「政务办公助手」禁 shell | 确认 `scenario` 已改且 `gateway restart`；新开对话再试 |
| curl 有 approve、聊天无弹窗 | 宿主必须真的调用对应工具（如 `write`），且客户端支持 `requireApproval` |
| 改了策略不生效 | 重启策略引擎进程 |
